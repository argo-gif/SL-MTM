Project Description: Dashboard Pemenuhan Service Level MTMNama Proyek: Interactive MTM Service Level KPI & Pareto Analytics DashboardBrand Identity: Tema visual bernuansa Merah Konimex lengkap dengan penempatan logo resmi Konimex di header dashboard.
1. Ringkasan & Tujuan ProyekProyek ini bertujuan untuk membangun dashboard analitik interaktif yang memonitor performa Key Performance Indicator (KPI) Service Level MTM (Make-to-Measure / distribusi). Sistem ini dirancang untuk menyajikan data pencapaian pemenuhan pengiriman vs. realisasi, melacak tren performa bulanan, mengidentifikasi akar masalah keterlambatan/ketidaksesuaian melalui visualisasi Tree Maps Pareto multi-dimensi, serta mengotomatisasi ekspor presentasi laporan ke format PowerPoint (PPT) sesuai standarisasi perusahaan.
2. Spesifikasi Fungsional & Modul SistemAutentikasi & Hak Akses UserOtentikasi: Sistem login wajib dengan kredensial:User: admin atau konimexPassword: konimex123Session Guard: Sesi otomatis berakhir (logout) dan kembali ke halaman login saat browser/tab dashboard ditutup.Role Management: Fitur upload data file Excel hanya dapat diakses oleh user berhak akses admin.Manajemen Data & Metrik TampilanInput Data: Pengunggahan berkas Excel menggunakan struktur template baku pada folder sistem.Metrik Pengukuran: Toggle switcher untuk mengubah tampilan dashboard berbasis nilai Rupiah (IDR) atau kuantitas unit Qty (default tampilan awal: Rupiah).Sistem Filter Terintegrasi (Global Linked Filters)Semua filter saling terkoneksi (cascading), mendukung pencarian teks (searchable), dan seleksi ganda (multi-select):Bulan Pengiriman (Delivery Date): Default menampilkan bulan transaksi terakhir.Jenis MTM: Default terpilih KA (Key Account).Dimensi Lain: Filter Cabang, MTM Alias, Grup Brand, serta Item / Nama Item.Logika Kondisional Filter Alasan:Alasan Kirim terisi & Alasan Realisasi kosong $\rightarrow$ Menggunakan Alasan Kirim.Alasan Kirim kosong & Alasan Realisasi terisi $\rightarrow$ Menggunakan Alasan Realisasi.Alasan Kirim & Realisasi keduanya terisi $\rightarrow$ Menggunakan Alasan Kirim.
3. Komponen Visualisasi & Analisis DashboardRingkasan KPI Service LevelIndikator Pencapaian: Kartu metrik (Scorecard) yang menampilkan Service Level (SL) Kirim, SL Realisasi, dan Gap/Selisih Realisasi vs. Kirim.Target Acuan: Garis batas performa target tetap sebesar 85%.Data otomatis disesuaikan dengan kombinasi filter global yang aktif.Analisis Tren Bulanan (Monthly Performance Trend)Grafik garis (Line Chart) performa dari bulan yang dipilih beserta bulan-bulan sebelumnya (historical run rate).Filter seleksi metrik grafik: SL Kirim (default) vs. SL Realisasi.Analisis Komposisi Tree Maps (Pareto Focus)Visualisasi Tree Maps interaktif berbasis urutan kontribusi terbesar ke terkecil (descending Pareto).Tampilan visual terpisah per lembar (dedicated tabs/sheets):Sheet AlasanSheet MTM AliasSheet CabangSheet Grup BrandSheet Item / Nama ItemInteraktivitas (Cross-Filtering): Klik pada blok kotak Tree Maps akan memfilter seluruh dashboard berdasarkan elemen tersebut; klik di area luar kotak untuk membatalkan seleksi (reset filter).Tabel Detail Data AnalisisGrid data tabular komprehensif yang menampilkan rincian data transaksi, kalkulasi pemenuhan, dan klasifikasi Pareto pendukung visualisasi.
4. Modul Otomasi Ekspor PowerPoint (PPT)Seleksi Konten: Opsi centang (checkbox) untuk memilih modul tampilan tertentu yang ingin diekspor.Otomasi Sheet Pareto: Mencetak seluruh sheet Tree Maps dan tabel detail secara terstruktur.Layout Safeguard: Penempatan tangkapan visual disesuaikan secara presisi agar rasio tampilan pas (fit-to-slide saat presentasi/slide show) dan tidak menimpa posisi logo Konimex di sudut kanan atas template.
